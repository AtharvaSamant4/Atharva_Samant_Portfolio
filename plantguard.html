PlantGuard 🌱

AI-Powered Plant Disease Detection

Deep Learning Keras Flask

Project Overview

Developed a CNN-based solution for detecting diseases in 11 different crops with 94% accuracy. Integrated real-time weather data analysis to provide preventive recommendations.

Key Features

  • Image classification using ResNet-50
  • Weather API integration
  • Farmer-friendly web interface

Technologies

  • Python
  • TensorFlow
  • OpenCV

Project Highlights

🔍 The Challenge
  • Manual disease detection is time-consuming (5-7 days for expert diagnosis)
  • 30-40% crop loss due to late disease identification
  • Limited expert access for 73% small-scale farmers
⚙️ Technical Core
Model Architecture
  • ResNet50 with 23M parameters
  • 3-stage verification pipeline
  • Weather data integration layer
Performance Metrics
  • 98.2% leaf detection accuracy
  • 94.5% plant classification accuracy
  • 79.8% disease prediction accuracy

1. Leaf Verification

3. Disease Prediction

ResNet50 + weather context analysis
